# Antigravity 0.1.5：安全优先的兼容与请求控制

## 批准范围与基线

用户已确认优化重点，并要求从 GitHub 的 0.1.4 继续迭代、测试后上传 GitHub。2026-10-13 核对结果：`origin/main` 与 `v0.1.4^{}` 一致，提交为 `cb9797f417583c24b03e885fa452ee0f6ab27c6e`；基线 25 项测试通过。当前 Desktop 请求代码与该基线只有两处版本字符串不同，Web/Desktop 安装包仍声明 0.1.3 和旧仓库来源。新版本为 0.1.5。

本设计降低错误请求、过量请求和凭据泄露风险，不声称隐藏第三方身份、不承诺防封、不伪装官方客户端、不绕过权限、地区或配额限制。开发中只使用离线 fixture，不发送 Google 真实模型请求；不替换已安装插件，不重启当前应用。

## 1. 工具 Schema 兼容

将转换逻辑抽出为 `lib/tool-schema.js`。纯函数 `convertToolDeclarations(tools, legacy)` 返回上游 `functionDeclarations` 数组；`ToolSchemaError` 携带固定 `INVALID_TOOL_SCHEMA` code、工具名和 JSON Pointer，但不泄露参数值。

Gemini 使用 `parametersJsonSchema`：保留 `$defs`/`definitions` 与 `$ref`、组合与嵌套结构；只在 schema 节点处理元数据，不把属性名当关键字。对本地 JSON Pointer 引用进行有界验证，不进行远端取回。缺失目标、外部引用、非法 JSON、原生对象循环、过深/过大的结构发送前失败。合法 JSON Schema 递归引用在 Gemini 路径保留，不通过无限展开解决。

Legacy 路径使用 `parameters`：在有界范围内展开本地引用；支持现有 type、description、properties、required、items、字符串 enum，以及可无损化简的 nullable 单类型。不能安全表示的组合、递归引用、验证约束不能静默删掉，应本地报错。多类型 MCP 工具在 Gemini 路径完整支持；Legacy 的限制在文档中明确公开。

请求开始时、OAuth 刷新和目录请求之前执行 Schema 预检。每次生成独立副本，跨模型切换不得改变调用者对象。

## 2. 请求错误与重试策略

将纯 HTTP 分类、等待时间解析与可中断等待抽出为 `lib/request-policy.js`。`classifyHttpFailure(status, text, headers, now)` 返回 `{code, retryable, cooldownMs, suspendAccount}`；`waitForRetry(ms, signal)` 支持取消且移除监听器。

400/401/403/404/409 和其它非瞬时 4xx 不换端点重试。401/403 暂停该账号直至用户重新授权；429 返回给用户，不在同一调用内更换账号、端点或模型。等待时间取 `Retry-After`（秒数或 HTTP 日期）、Google `RetryInfo.retryDelay` 的最大有效值，缺省 60 秒；不得缩短服务端等待时间。

生成请求最多 2 次 HTTP 尝试，总预算跨端点，禁止两轮 × 多模型 × 多端点放大。只对网络连接失败、500/502/503/504 在未开始接收生成流且未输出任何 chunk 时有限重试。取得成功响应并开始读流后失败，不再自动重放，即使还没有向用户交付内容，也不能证明后台未执行。第一次瞬时失败后至少等待 1 秒，并遵守有效 Retry-After；取消立即结束。显式 `ANTIGRAVITY_BASE_URL` 固定该入口，不暗中追加其它入口。默认端点仅保留现有 primary 与 daily，不使用 sandbox 绕过地区拒绝。模型路由可以读取目录，但拒绝响应不导致静默切换模型。

文本和图片使用统一分类、重试总预算、账号暂停逻辑。元数据调用改为顺序、有界（最多 2 次），不得对 401/403/429 继续换端点，目录不得同时向所有端点广播。缓存与 OAuth refresh 按账号/凭据复用在途请求，避免并发造成重复刷新。

## 3. 账号池与暂停状态

`getCandidateAccounts` 只返回可用账号：冷却中的、权限暂停的账号不会出现在列表尾部。manual 模式只返回指定账号，不能回退到其它账号。primary-backup 和 auto 仍可在一次新请求开始前选择健康账号，但任何一次请求遭到 401/403/429 后都立即结束。

429 同时写入该账号冷却和 provider 级持久暂停 `requestBlockedUntil`，因此下一次自动请求也不能立即换号继续。暴露状态 `requestPauseRemainingMs`、每账号 `suspended` 和固定错误码给本地设置页；重新登录解除账号权限暂停，但不提前解除 provider 级限流暂停。暂停只随真实时间到期；成功的额度刷新不清除生成限流。

池内原有凭据、额度与目录兼容保留。不读取、发布或打印真实用户凭据。

## 4. 凭据与日志

抽出 `lib/security.js`：共享脱敏函数和原子私密 JSON 写入。创建随机、排他临时文件（0600），写入后 rename；确认当前路径不为符号链接，不覆盖未知链接目标；修复既存文件权限，异常不留下包含凭据的临时文件。账号池、旧凭据存储使用同一个写入函数。

日志使用固定分类、内部账号 ID、端点主机、尝试次数、版本和耗时；不输出邮箱、OAuth URL、项目 ID、请求体、工具参数、响应体或凭据。需要展示的错误经过共享脱敏并限长，池持久错误也经脱敏。拒绝身份伪装、随机身份或风控绕过配置。

## 5. 版本、界面、发布

版本从包元数据读取，状态 API、诊断和请求日志不再各自维护硬编码。更新中英文 README 与设置页文案，明确 429 不自动换号、manual 真正固定、暂停状态、Legacy 兼容边界和非官方集成风险。添加离线 Node 20/22/24 CI。

## 验收

- 原基线保留的行为测试通过；旧测试中 429 回退、冷却账号尾部候选、显式入口被覆盖改为新行为测试，记录这是明确设计变化。
- Schema 引用、关键字同名属性、数组组合、递归、坏指针、外部引用、Legacy 无损/拒绝、跨模型不变性均有测试。
- 400/401/403/429 单次生成请求；Retry-After 日期/秒、RetryInfo、默认冷却、跨请求持久暂停；恢复与 manual 限定有测试。
- 瞬时失败最多 2 次、等待可取消、取到成功响应后读流失败不重放；文本和图片同样受限。
- 状态不返回 token；日志不包含测试邮箱/凭据/响应体；存储权限为 0600，符号链接拒绝和临时文件清理有测试。
- `npm test`、`npm run check`、打包与独立评审均通过后再发布。
